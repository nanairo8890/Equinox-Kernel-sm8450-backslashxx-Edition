# Equinox Kernel backslashxx Edition: Changelog

Edition by Nanairo8890, with permission from LF52406
Based on Equinox Kernel 5.10.269 for the POCO F5 Pro / Redmi K60 (`mondrian`)
Problems with this edition: report them to Nanairo8890, not to LF52406 or backslashxx

---

## 1.0 (2026-11-18)

First release of this edition

**backslashxx/KernelSU**
- backslashxx/KernelSU v3.3.1+52 (UAPI 6) instead of FinaSU, built in as the `KernelSU/` submodule
  Uses its own hook backend (syscall table / ARM64 branch-link), not FinaSU's Tracepoint hook
  Official backslashxx manager (package `me.weishu.kernelsu`)

**SUSFS v2.4.0 and NoMount v2.3.0**
- backslashxx ships no SUSFS support of its own: a new interface was written for this edition
  (`KernelSU/kernel/extension/susfs.c`), with the SID lookups, the zygote/zygote_next umount
  handling and the SELinux rule registration
- NoMount v2.3.0 stays the same as the other editions: built in, hidden from `/sys/module` and `/proc/kallsyms`
- SUSFS and NoMount are controlled from their own root modules (`ksu_module_susfs` and the
  NoMount metamodule), installable from backslashxx's manager like any KernelSU module

**`/proc/kallsyms` filter**
- Reworked for backslashxx's own symbols: down to 0 symbols that give away root
  (the only symbols still visible are generic memory-access helper copies already present
  hundreds of times in any stock kernel, unrelated to the driver)

**What stays the same**
- BBR, DroidSpaces and the installer

**Verified**
- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` added)
- Vendor module CRCs match (337 `vendor_boot` and 390 `vendor_dlkm`) with MistOS 20261025 and
  with 11 of the 11 applicable Keosh ROMs; AOSPA and PenguinOS are not on this list since they
  use their own kernel
- The build shows no warnings of its own
- The `/proc/kallsyms` filter was checked against the compiled kernel
