# Equinox backslashxx Edition 1.0
Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
backslashxx edition by **Nanairo8890** with LF52406's permission
First release of this edition. backslashxx/KernelSU v3.3.1+52 replaces FinaSU as the root implementation
## Files
- `Equinox-5.10.269-backslashxx-1.0-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig
- `Equinox-5.10.269-backslashxx-1.0-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog
## Before flashing
- Back up your `boot` partition first
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel
- Install backslashxx's own manager (from its own releases, package `me.weishu.kernelsu`); this kernel
  does not bundle or require a modified manager
- Flash `ksu_module_susfs` and the NoMount metamodule as plain root modules from the manager to
  control SUSFS and NoMount; neither needs a special manager
## What this edition changes
- **backslashxx/KernelSU `v3.3.1+52`** (UAPI 6) instead of FinaSU, built in as the `KernelSU/` submodule.
  Uses backslashxx's own hook backend (syscall table hooking, `KSU_TAMPER_SYSCALL_TABLE`, Clang CFI compliant), not an inline
  fs/exec.c hook
- **SUSFS v2.4.0**: backslashxx ships no SUSFS support of its own, so a dedicated interface
  (`KernelSU/kernel/extension/susfs.c`) was written for this edition, wiring SUSFS's SID lookups,
  zygote/zygote_next umount handling and SELinux rule registration onto backslashxx's own code
- Same NoMount v2.3.1, BBR, DroidSpaces, `/proc/kallsyms` filter (reworked for backslashxx's own
  symbols) and installer as the other editions

## Compatible ROMs

Exports the same symbol CRCs as the other editions, so the same ROMs are compatible:

- **Compatible:** MistOS 20261025; the latest builds from Keosh: crDroid, Evolution X, Infinity-X,
  Lunaris, LineageOS and Axion
- **Not compatible:** AOSPA and PenguinOS. They use their own kernel and the installer stops on them

## Checks

- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added)
- Vendor module CRCs match (337 from `vendor_boot` and 390 from `vendor_dlkm`) for MistOS 20261025
  and for 11 of the 11 applicable Keosh builds; AOSPA and PenguinOS are still not compatible
- The build shows no warnings of its own
- The `/proc/kallsyms` filter was checked against the compiled kernel: no symbol from the root driver
  or from NoMount gives away root
- Tested on the phone (POCO F5 Pro, MistOS 5.1 Beta 20261025) with one boot from `fastboot boot`, nothing flashed: SELinux is Enforcing, `su` works, the backslashxx manager reports it as working, `nm version` reports 23 (785), NoMount loads, SUSFS v2.4.0 is initialized with all its features, `dmesg` shows no Oops or panic, and `/proc/kallsyms` shows none of the root-revealing names
